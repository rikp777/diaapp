# Diavoorstelling

Een eenvoudige diavoorstelling voor foto's en filmpjes, vergelijkbaar met de
diavoorstelling van Windows Foto's. Alles zit in één bestand (`index.html`) en
werkt zonder internet of installatie. Je bestanden blijven op je eigen
computer; er wordt niets geüpload.

## Gebruik

1. Open `index.html` in Chrome, Edge of Firefox (dubbelklikken is genoeg).
2. Kies bestanden of een hele map, of sleep ze naar het venster.
3. Stel in hoeveel seconden elke foto te zien is en klik op **Diavoorstelling starten**.

Bestanden worden op naam gesorteerd, met getallen in de goede volgorde
(`foto2` komt vóór `foto10`).

## Instellingen

| Instelling | Uitleg |
| --- | --- |
| Seconden per foto | 1 tot 3600 seconden. Ook tijdens de voorstelling aan te passen in de balk of met `+` en `−`. |
| Filmpjes | *Helemaal afspelen* (standaard) of *Zelfde tijd als foto's*. |
| Geluid van filmpjes uit | Filmpjes zonder geluid afspelen. |
| Willekeurige volgorde | Husselt de volgorde. |
| Herhalen na laatste | Begint na de laatste dia weer opnieuw. |
| Scherm vullen | Snijdt foto's bij zodat er geen zwarte randen zijn. |

Instellingen worden onthouden in de browser.

## Bediening

| Toets / actie | Functie |
| --- | --- |
| `Spatie` of klik in het midden | Pauze / afspelen |
| `→` of klik rechts | Volgende |
| `←` of klik links | Vorige |
| `+` / `−` | Een seconde langer / korter per foto |
| `F` of dubbelklik | Volledig scherm aan/uit |
| `M` | Geluid aan/uit |
| `S` | Willekeurige volgorde aan/uit |
| `Home` / `End` | Eerste / laatste dia |
| `Esc` | Volledig scherm verlaten, nog een keer om te stoppen |

Beweeg de muis om de bedieningsbalk te tonen; na een paar seconden verdwijnt hij weer.

Welke filmpjes werken hangt af van de browser. MP4 (H.264) en WebM werken overal;
MOV en MKV meestal in Chrome en Edge.
